# Supabase Database Configuration

This directory contains the database schema, migrations, and test scripts for the **REclaim – Lost & Found Management System**.

## Schema Architecture

- `auth.users`: Supabase-managed authentication authority (passwords, tokens, sessions).
- `public.users`: Application user profiles, linked via UUID foreign key to `auth.users.id`.
- `public.items`: Lost and found items with geospatial coordinates (PostGIS).
- `public.claims`: Item claim records, reviews, and status lifecycle.
- `public.notifications`: User notifications generated by matching algorithm and claim actions.
- `public.audit_logs`: Comprehensive system activity and security audit trail.

## Migrations

1. `001_create_users.sql`: Users table, auth sync triggers, and role escalation prevention.
2. `002_create_items.sql`: Categories, locations, items, images, and spatial indexes.
3. `003_create_claims.sql`: Claims, claim images, and self-claim prevention trigger.
4. `004_create_notifications.sql`: Notifications, audit logs, and AI-assisted matching algorithm.

To inspect schema metadata:
```bash
cd ../backend && npm run inspect:schema
```
